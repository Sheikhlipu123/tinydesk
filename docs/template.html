Tiny Desk: an anonymous notice board and message desk for Tor onion services

A minimal, JavaScript-free self-hosted app. Post notices and files, and let visitors send anonymous messages with no account, e-mail or name. One Python file, built on Flask and SQLite. Runs on Linux, macOS and Windows.

Features

Notices

Public posts with image or .txt attachments, optional countdown timers, draft and hide controls.

Anonymous messaging

Visitors get a Ticket and Key. No account, e-mail or name. Messages are stored AES-256-GCM encrypted, and visitors can delete their own thread at any time.

No JavaScript

Server-rendered pages with a strict Content-Security-Policy. Threads refresh through a meta-refresh iframe.

Downloads with expiry

Operator-uploaded files of any type, served as attachments. Set an expiry and the file stops being served at once, then is scrubbed and securely deleted by the purge task.

Hardening

CSRF tokens on every POST, Argon2 admin password, short-lived admin sessions, request size limits, rate limits, magic-byte checks on attachments.

Housekeeping

Storage quotas, retention-based purge, expired-download purge, orphan file sweep, and a check command that verifies SHA-256 hashes.

Runs anywhere

Works on Linux, macOS and Windows. Use Gunicorn on Linux and macOS, and waitress on Windows.

Tiny Desk vs. similar tools

Pick the tool that matches your threat model. Tiny Desk is a lightweight contact desk, not a whistleblowing platform.

Hush Line

Built mainly as a one-way tip line with PGP-encrypted messages. Choose it when the server operator must not read messages. Tiny Desk adds two-way threads, notices and downloads, but the operator can read messages.

SecureDrop and GlobaLeaks

Full whistleblowing platforms for newsrooms and organizations. Choose them for high-risk sources. Tiny Desk is far simpler to run and offers less protection.

OnionShare

A desktop app that starts a temporary onion service for sharing files, receiving files, hosting a page or chatting. Tiny Desk is a persistent server with threads, notices and downloads.
